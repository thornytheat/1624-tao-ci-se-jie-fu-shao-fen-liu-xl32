# 陶瓷色阶复烧分流业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括白釉墙砖、浅釉地砖、哑釉门砖、墨釉装饰。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `soak_temp` | 保温温度 ℃ | 990 至 1240 |
| `glaze_sg` | 釉浆比重 | 1.1 至 2.0 |
| `cool_rate` | 冷却速率 ℃/min | 1 至 18 |
| `moisture` | 坯体湿度 % | 0.4 至 11 |
| `refires` | 已复烧次数 | 0 至 3 |
| `sheet_area` | 装窑面积 m² | 4 至 70 |
| `approved` | 是否开放复烧 | 0 至 1 |

## 计算与裁决

使用CART 回归树，目标单位为 ΔE。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

| 派生特征 | 计算 |
| --- | --- |
| `soak_deviation` | `abs(soak_temp-1130) / 140` |
| `water_glaze` | `glaze_sg * moisture / 20` |
| `quench` | `cool_rate / 18` |
| `loading` | `sheet_area / 70` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括签样冻结或已到复烧上限。最终分派受炉前试片装窑位总额和组内上限约束，使用额度守恒回读工作单。
