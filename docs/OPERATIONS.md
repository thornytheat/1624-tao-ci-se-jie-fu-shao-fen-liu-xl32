# 陶瓷厂烧成检验员交班

1. 从总览核对 炉前试片装窑位的当班余额和已冻结单据。只在确认资源可用后试算额度。
2. 回读独立回放的覆盖数量、参考误差和关键分组。触发人工复核的单据按原因调阅源记录，再由班组另行确认。
3. 对照资源使用和逐单结果。系统保留组内上限和业务锁，跨班窗口留待下一班处理。
4. 当前方案确认后登记，记下版本号和运行标识。下一次试算以最近登记版本为基线，回查时按版本读取原证据。

5. 同日改签只在原窑位、组限和收益排序上增量处理。窑位与组限都有余量时，合格候补与原单同时签出；发生挤退时，候补预测下界必须严格高于每张被挤原单签出时冻结的上界，比较使用未二次舍入的十进制界值。原单新触发签样冻结时先撤签并退回窑位，即使当前没有候补也成立。两班按同一版本提交不同改签时，只有先登记的一份生效，落败方必须基于新版本核对后再提交。

行业动作名称为「签出复烧试片」。同一方案重试仍回到原版本。
